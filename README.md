# 照護評估系統（日間照顧／小規模多機能・職能治療評估）

給長照日間照顧中心職能治療師用的**本機**評估系統：六力（ICOPE）評估、D61 職能治療評估、輔具、自立支援目標追蹤，
並可一鍵匯出評鑑佐證（Word／PDF／Excel）。欄位對照 care99 PCSMS 系統 D61，方便同步登打。

## 🌐 線上試用（免安裝）

**https://mattsue1003.github.io/care-assessment-system/** 　帳號 **1111**／密碼 **1111**

- 手機、平板、電腦打開就能用；個案全部是去識別化的假名
- 試用時的修改只存在自己的瀏覽器（各自一份，互不影響）；「設定」可重設回初始示範資料

- 網頁版放在 `docs/`（由 `build_pages.py` 從 `demo/demo.db` 產生資料），PDF 用瀏覽器「列印 → 另存為 PDF」，Word 為 .doc 格式

## 依 care99 實際紀錄做的優化（2026-10 分析）

把 care99 的紀錄全部讀出來分析「哪些內容一直重複打」，做成選項、範本或自動產生：

| 誰在用 | 原本（care99） | 實際紀錄發現 | 新系統 |
|---|---|---|---|
| 照服員 | 生命徵象 D71、如廁 D72、照顧紀錄 D75 三張表，每人每天各填一次 | 進食 71%「部份協助／全部吃完」、飲水 77%「750–1000」；「個別化」3,344 筆全空白；呼吸、體重幾乎都填 0 | **今日照顧紀錄**：三張合一、一人一列，自動帶入每位長輩平常的狀況，只改例外；體溫／血壓異常自動標紅 |
| 營養師／護理師 | 營養評估 D60a 手算 BMI、手填分數 | 3 筆 BMI 填 0；臂圍、小腿圍寫在備註；建議句固定格式 | **營養評估**：BMI、分數、判讀自動算；建議句（飲食質地、份數、熱量、給水）自動產生 |
| 社工 | 家訪 D21 每次重寫全文 | 48% 句子與同個案上一次完全相同；結論、問題分析固定句型 | **家訪紀錄**：自動沿用上次各段、標示有改的段落；問題分析勾選；結論依服務日與代碼自動產生 |
| 社工 | 電訪 D22 | 家屬姓名／關係手打 935 次；「定期電訪」520 次；「持續追蹤。」149 次 | **電訪紀錄**：家屬從過去紀錄帶出、事由選項、常用語範本；**群組電訪**一次通知多位家屬 |
| 社工／護理 | 異常服務 D23 | 事件類型、通知對象都在全文裡 | **異常事件**：事件類型、已通知對象（家屬／護理師／119…）勾選 |
| 社工 | 其他日常 D25（月底照顧紀錄） | 平均 339 字，內容多可由每日紀錄算出 | **月照顧摘要**：依該月每日照顧紀錄自動產生出席、生命徵象範圍、活動、飲食、情緒、異常事件 |

## 功能

| 功能 | 說明 |
|---|---|
| 首頁待辦 | 再評估逾期／30 天內到期／從未評估名單；評鑑指標 B1、B9、B10 進度 |
| B2 個案名冊 | 可從 Excel 名冊匯入／更新 |
| 六力 ICOPE 評估 | 點選作答，自動判定正常／異常；後續處置只列介入、團體、轉介；一鍵產生處置建議 |
| D61 職能治療評估 | 欄位同 care99 D61；「依六力帶入」「帶入上次」；自動產生整體評估建議初稿；與上次比較進步／退步；追蹤是否已登打 care99 |
| B2c 輔具（B9） | 開始使用、適配評估、使用訓練、檢查日期，缺漏自動提示 |
| 自立支援目標（B10） | 依六力異常面向一鍵建立目標，每 3 個月檢討紀錄 |
| 評鑑匯出 | 每張表 Word／PDF／列印；個案評估彙整；Excel 總表（7 張工作表）；**評鑑佐證包 ZIP**（依 B1／B9／B10 分資料夾） |
| 系統 | 多帳號、操作紀錄、每日自動備份（`data/備份/`，保留 30 份） |

## 日常流程建議

1. 首頁看逾期名單 → 「評估」
2. 六力評估 → 存檔時選「儲存並建立自立支援目標」
3. D61 → 「依六力結果帶入」→ 補其他欄位 →「✨ 依勾選自動產生」整體評估建議
4. 對照畫面登打 care99 → 勾「已登打」
5. 每 3 個月新增目標檢討；評鑑前到「評鑑佐證／匯出」下載 ZIP
