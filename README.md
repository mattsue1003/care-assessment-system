# 照護評估系統（日間照顧／小規模多機能・職能治療評估）

給長照日間照顧中心職能治療師用的**本機**評估系統：六力（ICOPE）評估、D61 職能治療評估、輔具、自立支援目標追蹤，
並可一鍵匯出評鑑佐證（Word／PDF／Excel）。欄位對照 care99 PCSMS 系統 D61，方便同步登打。

> 資料只存在自己電腦的 `data/care.db`，不會上傳雲端。`data/` 已列入 `.gitignore`，**請勿把正式資料上傳到 GitHub**。

## 快速試用（去識別化示範資料）

需要 Python 3.10 以上與 Google Chrome（產生 PDF 用）。

| 系統 | 示範版（可隨意操作） | 正式版 |
|---|---|---|
| macOS | 雙擊 `啟動示範版.command` | 雙擊 `啟動系統.command` |
| Windows | 雙擊 `啟動示範版.bat` | 雙擊 `啟動系統.bat` |
| 網址 | http://127.0.0.1:5051 | http://127.0.0.1:5050 |

- 預設帳號 **1111**、密碼 **1111**（登入後請到「設定」修改密碼）
- 示範資料在 `demo/demo.db`：45 位個案皆為**假名**，案號重編、出生日期與評估日期隨機偏移，電話地址等全部刪除
- 示範版會複製一份到 `data/demo_work.db` 來操作；要還原：`./啟動示範版.command --reset`

## 給單位試用：公開網址

`開啟公開試用.command`（macOS）會在本機跑示範版，並用 Cloudflare 通道產生 `https://xxxx.trycloudflare.com` 公開網址。
需先把 Cloudflare 官方 [cloudflared](https://github.com/cloudflare/cloudflared/releases) 放到 `tools/cloudflared`。
電腦要保持開機（程式會防止睡眠）；關掉視窗網址就失效，重開會換新網址。
示範版（`CARE_DEMO=1`）會關閉名冊匯入與帳號修改，並有「💬 意見回饋」可收集試用意見、匯出 Excel。

## 功能

| 功能 | 說明 |
|---|---|
| 首頁待辦 | 再評估逾期／30 天內到期／從未評估名單；評鑑指標 B1、B9、B10 進度 |
| B2 個案名冊 | 可從 Excel 名冊匯入／更新 |
| 六力 ICOPE 評估 | 點選作答，自動判定正常／異常；後續處置只列介入、團體、轉介；一鍵產生處置建議 |
| D61 職能治療評估 | 欄位同 care99 D61；「依六力帶入」「帶入上次」；自動產生整體評估建議初稿；與上次比較進步／退步；追蹤是否已登打 care99 |
| B2c 輔具（B9） | 開始使用、適配評估、使用訓練、檢查日期，缺漏自動提示 |
| 自立支援目標（B10） | 依六力異常面向一鍵建立目標，每 3 個月檢討紀錄 |
| 評鑑匯出 | 每張表 Word／PDF／列印；個案評估彙整；Excel 總表（7 張工作表）；**評鑑佐證包 ZIP**（依 B1／B9／B10 分資料夾） |
| 系統 | 多帳號、操作紀錄、每日自動備份（`data/備份/`，保留 30 份） |

## 日常流程建議

1. 首頁看逾期名單 → 「評估」
2. 六力評估 → 存檔時選「儲存並建立自立支援目標」
3. D61 → 「依六力結果帶入」→ 補其他欄位 →「✨ 依勾選自動產生」整體評估建議
4. 對照畫面登打 care99 → 勾「已登打」
5. 每 3 個月新增目標檢討；評鑑前到「評鑑佐證／匯出」下載 ZIP

## 其他

- 讓中心其他電腦／平板連線：`./啟動系統.command --lan`，其他裝置連 `http://這台電腦IP:5050`（請先改掉預設密碼）
- 由正式資料重新產生示範資料：`.venv/bin/python make_demo.py`（會檢查輸出不含任何真實姓名）
- 評鑑指標依桃園市 115 年社區式「小規模多機能」評鑑基準（附件2-3）

## 檔案結構

```
app.py        路由、資料庫、評鑑指標計算
schema.py     D61／六力表單定義、自動判定、建議用語與整體評估敘述產生
exports.py    Word（python-docx）、PDF（Chrome 無頭列印）、Excel（openpyxl）
importer.py   Excel 名冊匯入
make_demo.py  去識別化示範資料產生器
templates/    畫面與列印版面
demo/demo.db  去識別化示範資料
```
